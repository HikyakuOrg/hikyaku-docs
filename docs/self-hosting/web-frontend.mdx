# Web Setup

## Prerequisites

- Node.js 20+
- pnpm
- A provisioned Supabase project. Follow the [Supabase Setup](./supabase) guide first if you have not done this yet.

## Environment Variables

Copy `.env.example` to `.env.local` and fill in each variable as described below.

```bash
cp .env.example .env.local
```

### `NEXT_PUBLIC_SUPABASE_URL`

The base URL of your Supabase project. Every API call the frontend makes is routed through this URL.

**How to find it:**

1. On the **Project Overview** page, click on the dropdown menu.
2. Copy the value shown under **Project URL** (e.g. `https://abcdefghijklmnop.supabase.co`).

```
NEXT_PUBLIC_SUPABASE_URL=https://abcdefghijklmnop.supabase.co
```

---

### `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_OR_ANON_KEY`

The publishable key that the browser uses to authenticate requests to Supabase. Row-level security policies limit what this key can access, so it is safe to expose in client-side code.

**How to find it:**

1. On the **Project Overview** page, click on the dropdown menu.
2. Copy the value shown under **Publishable key**.

![Supabase Dashboard](/img/supabase-dashboard.jpg)
![Supabase Config](/img/supabase-dashboard-config.jpg)


```
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_OR_ANON_KEY=sb_publishable_xxx.
```

:::caution
Never use the **service role** key here. The service role key bypasses row-level security and must only be used in trusted server-side contexts.
:::

---

### `NEXT_PUBLIC_OSM_TILE_URL`

The tile server URL used by MapLibre to render base map tiles. The `{s}`, `{z}`, `{x}`, and `{y}` placeholders are substituted at runtime.

**Leave this blank (or set it to the default) to use the public OpenStreetMap tile server.** Set a custom URL if you are self-hosting tiles or using a commercial tile provider.

```
# Public OSM tile server (default)
NEXT_PUBLIC_OSM_TILE_URL=https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png

# Leave blank to fall back to the same default
NEXT_PUBLIC_OSM_TILE_URL=
```

---

### `NEXT_PUBLIC_HIKYAKU_API_URL`

The base URL of `hikyaku-api`, the NestJS backend. See the [NestJS API](./nestjs-api) guide for standing this up.

```
NEXT_PUBLIC_HIKYAKU_API_URL=http://localhost:3002
```

---

### `NEXT_PUBLIC_ROOT_DOMAIN`

The root domain tenants are reached at, as `<slug>.<root>`. Set this to the domain you control if you want subdomain-based customer booking sites — see [Before You Go to Production](./overview#before-you-go-to-production) for the wildcard TLS prerequisites.

```
# prod
NEXT_PUBLIC_ROOT_DOMAIN=hikyaku.org

# local
NEXT_PUBLIC_ROOT_DOMAIN=localhost:3000
```

---

### `TENANT_PROXY_SECRET`

A shared secret with the Cloudflare Worker in `workers/tenant-proxy`, which serves the `<slug>.hikyaku.org` vanity hosts. The middleware only trusts the tenant host the Worker forwards when this value matches, so it must be identical in both places. See [Architecture → Why the Worker exists](../architecture#why-the-worker-exists) for the full reasoning.

```
TENANT_PROXY_SECRET=$(openssl rand -hex 32)
```

:::note
Leave this unset for local development. Subdomains resolve straight to the dev server, so the `Host` header is already correct and no proxy is involved.
:::

---

### `NEXT_PUBLIC_GOOGLE_CLIENT_ID`

The Google OAuth web client ID, from the [Google Cloud Console](https://console.cloud.google.com/apis/credentials) under **Credentials**. Drives the "Sign in with Google" button and One Tap on the auth pages — the buttons render only once this is set.

```
NEXT_PUBLIC_GOOGLE_CLIENT_ID=xxxx.apps.googleusercontent.com
```

:::caution
The matching client **secret** is not used by this app. Paste it into the Supabase dashboard instead, under **Authentication → Providers → Google**, and add this same client ID to that provider's **Authorized Client IDs** field — otherwise `signInWithIdToken` will reject the token.
:::

---

### `NEXT_PUBLIC_WEBAUTHN_MFA_ENABLED`

Shows the "Add security key" control in account settings.

```
NEXT_PUBLIC_WEBAUTHN_MFA_ENABLED=true
```

:::caution
WebAuthn MFA enrollment is disabled by default on Supabase projects, and there is no Dashboard toggle for it yet. This variable must line up with a manual Management API call:

```
PATCH /v1/projects/<ref>/config/auth
{"mfa_web_authn_enroll_enabled": true, "mfa_web_authn_verify_enabled": true}
```

Leave this unset (or `false`) until that's confirmed enabled server-side, or the button will fail with "MFA enroll is disabled for WebAuthn".
:::

## Run the App

1. Clone https://github.com/hikyakuorg/hikyaku
2. Copy `.env.example` to `.env.local` and fill in each variable using the guidance above.
3. Install dependencies.
4. Start the development server.

```bash
pnpm install
pnpm dev
```

App URL:

- http://localhost:3000
